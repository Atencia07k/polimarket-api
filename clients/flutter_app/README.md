# PoliMarket Flutter

Cliente nativo Android y Windows. Consulta la [guía de ejecución, requisitos y demostración](../README.md).

Desde esta carpeta:

```powershell
flutter pub get
flutter run -d windows
flutter analyze
flutter test
```

Para Android usa `--dart-define=API_URL=http://10.0.2.2:8080/api/v1` en el emulador.
